# 🚀 Personal Portfolio Website
https://protfolio-nu-green.vercel.app/

A polished developer portfolio for Aditya Pratap Singh, designed for internship and freelance presentation. The site uses modern dark theming, responsive layout, and professional content that showcases beginner-friendly projects and technical skills.

## ✨ Features

- **SEO-ready metadata** with Open Graph tags and favicon support
- **Responsive layout** for desktop, tablet, and mobile screens
- **Smooth navigation** with active scroll highlighting and mobile menu
- **Professional CTAs** including resume download, GitHub, and LinkedIn access
- **Modern UI/UX** with clean spacing, subtle hover effects, and premium section styling
- **Project showcase** with realistic beginner project descriptions

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessible content
- **Tailwind CSS**: Utility-first styling for fast responsive design
- **JavaScript (Vanilla)**: Navigation, intro sequence, and reveal animations
- **Lucide Icons**: Lightweight icons throughout the site
