# 🚀 Personal Portfolio Website
https://kadityas807.github.io/Protfolio/  

Welcome to my personal portfolio website! This project showcases my skills, projects, and journey as a Full Stack Developer & AI Engineer. It features a modern, responsive design with immersive 3D effects and smooth animations.

## ✨ Features

- **3D Interactive Elements**: Includes 3D tilt cards for projects and a rotating 3D cube representing my tech stack.
- **Responsive Design**: Fully responsive layout that looks great on desktop, tablet, and mobile devices.
- **Dynamic Animations**: Smooth entrance animations, floating elements, and a binary rain effect for a tech-savvy feel.
- **Modern UI/UX**: Built with a dark-themed aesthetic using a curated color palette (Slate & Cyan/Blue).
- **Parallax Background**: Interactive background elements that move with your mouse cursor.
- **Scroll Spy Navigation**: Navigation bar that highlights the current section as you scroll.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure of the website.
- **Tailwind CSS**: Utility-first CSS framework for rapid and responsive styling.
- **JavaScript (Vanilla)**: Core logic for animations, 3D effects, and interactivity.
- **Lucide Icons**: Beautiful and consistent icons used throughout the site.

## 🚀 How to Run

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/kadityas807/Protfolio.git
    ```
2.  **Open the project**:
    Navigate to the project folder and open `index.html` in your preferred web browser.

    *Tip: For the best experience, use a modern browser like Chrome, Edge, or Firefox.*
